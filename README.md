
# Indian CPI Inflation Analysis Dashboard (2013–2023)

An interactive Excel-based Business Intelligence project analyzing India's Consumer Price Index (CPI) data to identify inflation patterns, category-level trends, and rural–urban differences.

## Project Overview

The objective of this project is to transform raw CPI data into meaningful business insights through data cleaning, data transformation, analysis, and interactive dashboard development.

The dashboard enables users to explore CPI trends across different years, months, sectors, and consumption categories.

## Business Objectives

- Analyze changes in India's CPI over time.
- Compare inflation patterns across Rural, Urban, and Rural+Urban sectors.
- Identify categories with relatively higher and lower CPI values.
- Understand monthly and yearly CPI trends.
- Present key findings through an interactive dashboard.
